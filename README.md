# Smart Shower

Smart Shower is a university project developed at Aarhus University to monitor water and energy consumption during showers. The goal is to encourage more sustainable shower habits by providing real-time feedback and consumption statistics.


## Features

Real-time monitoring of water consumption and temperature
Energy consumption calculations
Touchscreen GUI displaying live data and statistics
Audio feedback during shower sessions
User rankings to encourage reduced resource consumption

## Technologies

C++ – Arduino microcontrollers and sensor communication
Python (Flask) – Graphical user interface
Raspberry Pi – Data processing and system coordination
Arduino – Integration of flow and temperature sensors
Hardware – Flow sensor, temperature sensor, touchscreen and sound module

## Project Information

Developed as a second-semester group project for the B.Eng. in Software Technology at Aarhus University (2026).

The system was developed as a functional prototype, demonstrating the integration of embedded hardware and software for monitoring household resource consumption.
